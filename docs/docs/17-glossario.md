# Glossário

| Termo | Definição |
| --- | --- |
| API | Forma padronizada de comunicação entre programas; pode ou não usar internet |
| Backup | Cópia criada para recuperação após falha ou erro |
| Comanda | Sessão de consumo identificada por número e composta por itens |
| Domínio | Conceitos e regras centrais do negócio |
| Entity Framework Core | Biblioteca .NET usada para mapear e persistir dados no SQLite |
| Integridade | Garantia de que dados obedecem às regras e não ficam incompletos |
| Integração com maquininha | Comunicação com terminal compatível para enviar valor e receber situação; fora do MVP |
| MVP | Menor versão que resolve o problema prioritário e permite validação |
| Migração | Alteração versionada da estrutura do banco |
| MVVM | Organização que separa tela estado de apresentação e lógica de aplicação |
| Mutex | Bloqueio do sistema usado para impedir duas instâncias do aplicativo |
| Offline | Funcionamento sem conexão com a internet |
| Rollback | Desfazimento integral de uma transação que falhou |
| SQLite | Banco local armazenado em arquivo |
| Snapshot de preço | Cópia do nome e preço praticados para preservar histórico |
| Ticket médio | Total vendido dividido pela quantidade de vendas concluídas |
| Transação | Conjunto de gravações confirmado por inteiro ou totalmente desfeito |
| Venda | Registro histórico do encerramento e total da comanda; não é pagamento no MVP |
| WPF | Tecnologia .NET para construir a interface desktop no Windows |
