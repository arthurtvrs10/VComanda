# Diagramas

Os arquivos `.mmd` usam Mermaid e podem ser renderizados diretamente por ferramentas compatíveis ou copiados para blocos `mermaid` no GitHub.

A pasta `renderizados/` contém versões PNG para visualização imediata.

| Arquivo | Conteúdo |
| --- | --- |
| `01-contexto.mmd` | Sistema, pessoas, backup e maquininha externa |
| `02-processo-mvp.mmd` | Fluxo operacional completo |
| `03-estados-comanda.mmd` | Estados e transições |
| `04-sequencia-encerramento.mmd` | Mensagens no encerramento |
| `05-modelo-er.mmd` | Entidades e cardinalidades |
| `06-arquitetura.mmd` | Componentes técnicos |
